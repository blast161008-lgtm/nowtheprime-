# NOW THE PRIME

Сайт бренда NOW THE PRIME — Drop 002, футболка «The path is the prize».

- `index.html` — весь сайт. Цена, ссылка на СБП и Telegram — в блоке `CONFIG` в начале скрипта.
- Остатки по размерам — в блоке `<script id="ntp-stock">` (например `{"S":4,"M":10,"L":7,"XL":4,"XXL":0}`).
- `img/` — фото и логотип.
