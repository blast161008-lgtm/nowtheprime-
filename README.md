# ИИ-продюсер — Telegram-бот

Присылаешь боту публичный канал, а он:
- считает статистику: просмотры, охват, лучший формат, день и время;
- через ИИ объясняет, что заходит, а что нет, и даёт 5 идей постов с готовыми хуками;
- `/compare @мой @конкурент…` сравнивает с конкурентами;
- `/plan` делает контент-план на неделю.

Внешних зависимостей нет, нужен только Python 3.11+.

## Переменные окружения
| Переменная | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather (обязательно) |
| `AI_PROVIDER` | `anthropic` (Claude) или `openai` (OpenAI, OpenRouter, DeepSeek — всё, что совместимо с OpenAI) |
| `AI_API_KEY` | ключ ИИ. Без него бот присылает только цифры |
| `AI_MODEL` | модель. Для anthropic по умолчанию `claude-sonnet-5-5` |
| `AI_BASE_URL` | для openai-совместимых, например `https://openrouter.ai/api/v1` |
| `ADMIN_IDS` | твой Telegram ID. Админу лимитов нет, доступна команда `/stats` |
| `DAILY_LIMIT` | сколько разборов в день на пользователя (по умолчанию 5) |

## Запуск на компьютере
```
export TELEGRAM_BOT_TOKEN=...
export AI_API_KEY=...
python bot.py
```

## Render
Подключи репозиторий через New → Blueprint, затем заполни секреты. Бот сам переходит в режим вебхука: адрес он берёт из `RENDER_EXTERNAL_URL`.
